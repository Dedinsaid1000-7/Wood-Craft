# WoodCraft — Современный интернет-магазин мебели

Учебный проект интерактивного веб-сайта мебельного магазина с динамической фильтрацией товаров на JavaScript. Разработано в рамках лабораторной работы (Вариант/Тема №3).

## Ссылка на живой проект (Netlify)
Посмотреть работающий сайт можно здесь: 
 **[https://netlify.app](https://netlify.app)**

---

## Реализованный функционал

### HTML5 & CSS3
* **Семантическая разметка:** Использованы теги `<header>`, `<main>`, `<section>`, `<footer>`.
* **Макет:** Фиксированное (закрепленное) верхнее меню, главный экран (Hero), адаптивная сетка каталога на **CSS Grid** и гибкие элементы на **Flexbox**.
* **Дизайн:** Аккуратные отступы, кастомные интерактивные кнопки, плавные переходы (`transition`) и эффекты наведения (`hover`).

### JavaScript (ООП)
* Код вынесен в отдельный файл и запускается через `DOMContentLoaded` и `addEventListener`.
* **Объектно-ориентированный подход:** Карточки товаров генерируются динамически через JS-класс `ProductCard`. Каждый созданный объект сохраняет прямую ссылку на свой DOM-элемент.
* **Комбинированный фильтр:** Реализована фильтрация «на лету» одновременно по двум условиям: выпадающий список (категория) и числовое поле ввода (максимальная цена) с использованием механизма замыканий.
* **Интерфейс:** Валидация отправки формы с выводом структурированных данных в консоль браузера в виде `console.table()`. Динамическое модальное окно уведомлений (управление через `display: flex/none`).

##  Инструкция по локальному запуску проекта

Для того чтобы запустить и протестировать проект у себя на компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий** себе на компьютер с помощью Git:
   ```bash
   git clone https://github.com
   ```
2. **Перейдите в папку проекта**:
   ```bash
   cd Wood-Craft
   ```
3. **Откройте проект**:
   Зайдите в папку `html` и просто дважды кликните по файлу `index.html`, чтобы открыть сайт в любом современном браузере. Установка дополнительных серверов или зависимостей не требуется.
